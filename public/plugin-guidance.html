ERP System: Plugin Development Guide

This guide explains how to build, configure, and install plugins for your ERP system using the new Modular Architecture.

1. The Architecture

Your ERP uses nwidart/laravel-modules. Every plugin is a completely isolated miniature Laravel application living inside the Modules/ directory. A plugin has its own Models, Controllers, Filament Resources, and Migrations.

2. Creating a New Plugin (Locally)

To generate a new plugin scaffold while developing locally, run this command in your terminal:

docker exec erp-system-app-1 php artisan module:make MyNewPlugin

This will generate a folder at Modules/MyNewPlugin.

3. Targeting the Dashboard vs. Admin Panel

By default, if you create a Filament Resource inside your plugin (e.g., Modules/MyNewPlugin/Filament/Resources/InvoiceResource.php), it will automatically register to the Admin panel.

If you want the plugin's pages and resources to show up in the Dashboard panel for regular users, you must edit the module.json file located at the root of your plugin directory and add "panel": "dashboard":

{
    "name": "MyNewPlugin",
    "alias": "mynewplugin",
    "panel": "dashboard",
    "requires": []
}

4. Plugin Dependencies

If your plugin relies on another plugin to function (for example, an InvoicePlugin requires the CalendarPlugin), you can enforce this in the module.json using the requires array.

{
    "name": "InvoicePlugin",
    "requires": ["CalendarPlugin"]
}

The Plugin Manager UI will actively prevent the InvoicePlugin from being enabled if CalendarPlugin is not installed or is currently disabled.

5. Packaging & Installation

Once you have finished developing a plugin locally, you can package it for distribution or installation on the production server:

  1. Zip the plugin folder (e.g., compress Modules/MyNewPlugin/ into MyNewPlugin.zip).
  2. Go to the Admin Panel > System > Plugin Manager.
  3. Click Upload Plugin (.zip).
  4. The system will automatically extract it, register the classes, and list it in the table.
  5. Click the green Enable button to automatically run the plugin's database migrations and activate it.
Example Plugin: I have generated a fully working example plugin for you called ExamplePlugin.zip. It is located in the root directory of your project folder (D:\Projects\erp-system\ExamplePlugin.zip). You can test the system right now by uploading this ZIP file via the Plugin Manager!
